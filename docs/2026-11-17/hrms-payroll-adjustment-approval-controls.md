# HRMS Payroll Adjustment Approval Controls

## Scope
Define how off-cycle earnings, deductions, reimbursements, and corrections are requested, reviewed, approved, and recorded.

## Controls
- Require a reason and source reference for each adjustment.
- Separate request and approval permissions where policy requires it.
- Prevent an approver from approving an adjustment they created when segregation is required.
- Preserve the original payroll result and record adjustments as traceable entries.
- Prevent duplicate submission and duplicate posting.

## Test cases
Cover unauthorized approval, self-approval, rejected adjustment, duplicate request, adjustment after period close, and reversal. Verify audit history and payslip reconciliation.
